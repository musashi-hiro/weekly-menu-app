# こんだてウィークリー (Weekly Menu Planner)

毎日の夕食の献立決めをシンプルにし、買い物リストもワンタップで自動作成できるモバイル＆Webアプリです。  
Google Play ストアで販売（有料買い切り版）または無料配信できる構成（Capacitor + React）で構築されています。

---

## 🍳 主な機能

1. **一週間の夕食献立表（月〜日）**
   - 主菜（メイン）・副菜（サブ）・汁物（スープ）の3品をシンプルに管理
   - 40種類以上の定番家庭料理データベースからワンタップで選択可能
   - 自由テキスト入力（「外食」「冷蔵庫の残り物」など）も対応
   - 曜日ごとの「再抽選（シャッフル）」ボタン

2. **「今週ぜんぶおまかせ！」自動提案**
   - 魚・豚肉・時短中華・鶏肉・カレー/洋食・週末のごちそうなど、栄養・味の黄金バランスで一週間の献立を一瞬で自動決定

3. **自動買い物リスト**
   - 決まった献立から必要な材料を自動抽出し、食材ジャンル別（お肉・お魚、野菜、乳製品、調味料等）に分類
   - スーパーでの買い物中にチェック可能
   - LINEやメール、家族に送れる「テキスト共有（クリップボードコピー）」機能
   - 献立以外の食材・日用品も自由に手動追加可能

4. **お気に入り・セット保存**
   - 作成した一週間献立に名前をつけて何パターンでも保存可能
   - ワンタップで今週の献立に一括呼び出し
   - 「黄金バランス定番セット」「忙しい人の超時短スピードセット」などの公式プリセットも搭載

5. **安心の完全ローカル保存**
   - ログインや会員登録が不要
   - データはお使いのスマホ端末内（LocalStorage）に保存されるため、電波のない地下スーパーでも快適・高速に動作

6. **デザイン・UI**
   - スマホ操作に最適化されたモダンなモバイルUI
   - ダークモード / ライトモード対応
   - Google Play審査に必要な「プライバシーポリシー」「使い方ガイド」をアプリ内に標準搭載

## 💻 起動・開発方法

### 開発サーバーの起動（ブラウザでの動作確認）
```bash
npm run dev
```
ブラウザで `http://localhost:5173` を開くと動作します。

### Web成果物のビルド
```bash
npm run build
```

### Androidプロジェクトへの反映
```bash
npx cap copy android
```

## 📱 Google Play ストアで販売・公開する手順

本アプリは **Capacitor（キャパシタ：Web技術で作ったアプリをAndroidアプリに変換する仕組み）** を使用しているため、以下の手順でGoogle Playに公開・販売できます。

### ステップ1: Android Studio で開く
```bash
npx cap open android
```
※ パソコンに Android Studio がインストールされている場合、プロジェクトが自動で開きます。

### ステップ2: 署名付きアプリファイル（AAB）の生成
1. Android Studio のメニューから `Build` > `Generate Signed Bundle / APK` を選択
2. `Android App Bundle (.aab)` を選択して `Next`
3. 新しいキーストア（アプリの所有者を証明する電子署名鍵）を作成、または既存の鍵を指定
4. ビルドタイプで `release` を選択して `Finish` をクリック
5. `android/app/release/app-release.aab` というファイルが生成されます

### ステップ3: Google Play Console への登録と販売設定
1. [Google Play Console](https://play.google.com/console/) にアクセス（初回のみ開発者登録費用 $25 が必要です）
2. 「アプリを作成」をクリックし、アプリ名「こんだてウィークリー」を入力
3. **有料販売する場合**:
   - アプリの基本設定で「有料」を選択し、販売価格（例: 200円〜500円）を設定
   - Google Playのマーチャントアカウント（売上を受け取る銀行口座等の連携）を設定
4. ストアの掲載情報（説明文、スクリーンショット、アプリアイコン）を登録
5. プライバシーポリシーのURLを登録（本アプリは外部への個人情報送信を行わないため、アプリ内のプライバシーポリシー文面をそのままご利用いただけます）
6. 先ほど作成した `.aab` ファイルをアップロードして審査に提出
7. Google側の審査（通常数日〜1週間程度）が完了すると、Google Playストアで販売が開始されます！
